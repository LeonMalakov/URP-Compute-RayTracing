# Unity URP Compute Shader Ray Tracing

An experimental ray tracing implementation built with Unity URP and HLSL Compute Shaders.

The project explores custom rendering techniques and GPU-based ray tracing integrated into Unity's rendering pipeline.

**Features:**

- Scene geometry extraction and GPU buffer generation
- Ray tracing implemented with Compute Shaders
- Textured surfaces, shadows, and reflections
- Custom rendering passes integrated into URP
- Spatial acceleration using a voxel-based structure
